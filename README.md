# 🤖 Crypto Scanner Bot (Bybit)

Цей бот — це автономна торгова система, яка сканує ринок ф'ючерсів на біржі **Bybit** і шукає патерн **«Пробій + Ретест»** на трьох таймфреймах (1H, 4H, 1D).

## 🚀 Що вміє бот
*   **Аналіз 50 монет** одночасно.
*   **Фільтрація фальшивих сигналів**: перевіряє об'єм, волатильність (ATR) та тренд Біткоїна (MA20).
*   **Ризик-менеджмент**: автоматично розраховує стоп-лосс і тейк-профіт так, щоб ризик на угоду становив не більше **7.8 USDT**. Співвідношення прибутку до ризику (R:R) — не менше **1:2.5**.
*   **Telegram-інтеграція**: надсилає найкращі сигнали прямо у ваш чат.

## 🛠️ Технології
*   Python 3
*   Bybit API (v5)
*   Telegram Bot API

## ⚙️ Як налаштувати
1. Встановіть залежності: `pip install requests`.
2. Відкрийте файл `strategy.py` і впишіть свій токен та Chat ID у змінні `TG_BOT_TOKEN` та `TG_CHAT_ID`.
3. Запустіть бота: `python3 strategy.py`.

## ⚠️ Застереження
Цей бот є інструментом для аналізу ринку, а не фінансовою порадою. Завжди перевіряйте сигнали вручну та використовуйте стоп-лосси.
